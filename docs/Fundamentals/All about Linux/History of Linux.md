#### Introduction

We often talk about Windows OS and macOS. But did you know there’s an _imposter_ in the room — a Penguin? Yes, that’s **Linux**. Some of you may have heard about it, some may not — but it’s one of the **most important topics to learn in Cybersecurity** today.

**Linux** is a powerful, free, and open-source operating system (OS) that runs across a vast range of devices — from personal computers to web servers, smartphones, embedded systems, supercomputers, and even space missions. Unlike commercial operating systems like **Microsoft Windows** and **Apple macOS**, Linux gives users complete control over its source code, allowing them to **modify**, **redistribute**, or **optimize** the system however they want. This makes it incredibly flexible, secure, and ideal for developers, ethical hackers, and cybersecurity professionals.

#### Timeline of Linux History

1. **UNIX – The Ancestor (1969)**

- Developed at **AT&T Bell Labs** by **Ken Thompson** and **Dennis Ritchie**.
    
- Multi-user, multitasking OS that inspired the Linux architecture.
    
- Written in **C language**, making it portable across systems.


2.  **The GNU Project Begins (1983)

- Started by **Richard Stallman** to create a **free UNIX-like OS**.
    
- Produced essential software tools: GCC (compiler), bash (shell), core utilities.
    
- The project lacked only a **kernel** (the OS core).


3. Linux Kernel is Born (1991)**

- **Linus Torvalds**, a 21-year-old student from Finland, began developing a kernel for learning purposes.
    
- **August 25, 1991**: Linus announced Linux on the **Usenet group** `comp.os.minix`.
    
- Released version **0.01**; later licensed under **GPL v2** for open-source collaboration.

4. **Linux + GNU = A Complete Operating System**

- Developers combined **Linux kernel** with **GNU software**.
    
- Created the first fully functional free and open-source operating system.
    
- This combination is often referred to as **GNU/Linux**.

5. **First Linux Distributions (1992–1994)**

- **Distributions (distros)**: Packaged versions of Linux with software and installer.
    
- Popular early distros:
    
    - **Slackware** (1993)
        
    - **Debian** (1993)
        
    - **Red Hat Linux** (1995)

#### Lets talk about use cases

- Linux gained popularity in **data centers**, **web servers**, and **networking**.
    
- Adopted by companies like **IBM**, **Oracle**, and **Red Hat**.
    
- **LAMP stack** (Linux, Apache, MySQL, PHP) became standard for web hosting.


- **2008**: Google launched **Android**, a mobile OS based on the Linux kernel.
    
- Linux began powering:
    
    - Smartphones
        
    - Routers
        
    - Smart TVs
        
    - IoT Devices
        
    - Industrial & Automotive systems


- Became dominant in:
    
    - **Cloud computing** (AWS, Azure, GCP)
        
    - **DevOps tools** (Docker, Kubernetes)
        
    - **Cybersecurity** (Kali Linux, Parrot OS)
        
- Runs **100% of the world’s top 500 supercomputers**.

- Powers:
    
    - Most internet servers
        
    - All smartphones running Android
        
    - Cloud infrastructure
        
    - Cybersecurity tools and firewalls
        
- Accessible via **distros** like Ubuntu, Fedora, Arch, Kali, and more.
    
- Available on **Windows** via **WSL (Windows Subsystem for Linux)**.
